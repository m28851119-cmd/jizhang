# 我要记账

> 打开就记，三秒记完一笔；月底看一眼图表，知道钱花在哪；数据全在自己电脑上。

「我要记账」是一款面向个人和家庭的**本地离线**桌面记账应用，支持 Windows 与 macOS，全中文界面，人民币记账。账目数据保存在您自己的电脑上，**不上传任何服务器**。

## ✨ 功能特性

- **记一笔**：金额、两级分类、日期、备注、支付方式，3 步内完成录入；常用分类自动记住
- **分类管理**：支持自定义一级/二级分类（添加、改名、删除、恢复默认），出厂自带 11 个常用大类，每个大类都有「其他」兜底小类
- **账单列表**：按日期倒序展示；可按月份、分类筛选；支持关键词搜索
- **编辑 / 删除**：任意账单可修改或删除，删除前有确认提示
- **统计图表**：本月总支出与日均摘要、分类占比环形图、分类排行
- **数据备份**：一键导出 CSV 表格（Excel 可直接打开）；一键打开数据文件夹
- **账目安全**：每笔改动即时保存到本地；删除分类不影响已有账单

## 💾 数据与隐私

- 账目数据存在本机的一个数据库文件里：`我的文档\我要记账数据\data.db`，格式开放，可随时备份、复制带走
- 应用**完全离线可用**，不依赖任何网络服务
- 账目数据是个人隐私，**绝不上传**，不会被「锁」在软件里

## 🚀 安装与使用

### 获取安装包

Windows 安装包暂未随仓库发布（体积较大）。如需安装包，可自行构建（见下）或联系作者。

### 从源码运行（开发者）

1. 安装 [Node.js](https://nodejs.org/) 20 或更高版本
2. 安装依赖：`npm install`
3. 启动：`npm start`

### 构建安装包

```bash
npm run dist:win   # Windows 安装包（正规安装向导）
npm run dist:mac   # Mac 安装包（zip，Windows 上亦可直接产出）
```

国内网络下载 Electron 失败时，构建前先设置镜像：

```bash
export ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
export ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/
```

> Mac 版未做苹果签名，首次打开若提示「无法验证开发者」，**右键点图标选「打开」**一次即可正常使用。

## 🛠️ 技术栈

| 项目 | 选型 |
| --- | --- |
| 应用框架 | Electron 40 |
| 界面技术 | 原生 HTML / CSS / JavaScript（无框架，启动快、结构简单） |
| 数据存储 | SQLite（Node 内置 node:sqlite，零下载零编译） |
| 打包工具 | electron-builder |

## 📂 目录结构

```
src/main.js            主进程：数据库与数据管理
src/preload.js         安全桥接
src/renderer/          界面（HTML / CSS / JS）
build/                 图标等资源
```
